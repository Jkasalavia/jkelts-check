Short Commands

Run the latest script directly from GitHub Pages. Windows and macOS use different shell commands because PowerShell and Bash are different environments.

Windows

irm https://jkasalavia.github.io/jkelts-check/run|iex

macOS

curl -fsSL https://jkasalavia.github.io/jkelts-check/run.sh | sudo bash

Why Use It

Built for quick triage when a user reports slow performance, storage issues, network problems, battery concerns, or Microsoft/Outlook symptoms.

Faster first look

Run one command and choose the exact section needed instead of opening many separate tools.

Portable workflow

No local project folder is required on the target computer. The launcher downloads the latest hosted script.

Clear technician output

Consistent section titles and status labels make results easier to read during support calls.

Available Checks

Coverage differs slightly by operating system because Windows and macOS expose hardware information differently.

Apple Silicon Macs may not expose numeric CPU temperature through native command-line tools. In that case JKELTS CHECK reports the limitation and uses thermal pressure as the native health indicator.
