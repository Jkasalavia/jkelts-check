JKELTS CHECK

Run the interactive Windows health check from PowerShell:

irm https://jkasalavia.github.io/jkelts-check/jk|iex

Windows smart alias:

irm https://jkasalavia.github.io/jkelts-check/run|iex

CPU-only check:

irm https://jkasalavia.github.io/jkelts-check/cpu|iex

Run the interactive macOS health check from Terminal:

curl -fsSL https://jkasalavia.github.io/jkelts-check/mac | bash

macOS smart alias:

curl -fsSL https://jkasalavia.github.io/jkelts-check/run.sh | bash

macOS CPU-only check:

curl -fsSL https://jkasalavia.github.io/jkelts-check/mac | bash -s -- --choice 1
